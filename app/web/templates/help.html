Batch CSV format

CSV with a header row. Recognized columns (only prompt is required):

  • prompt — the description
  • ref1, ref2, ref3, ref4 — paths to reference images reachable from the ComfyUI host
  • width, height — integers, default to your settings
  • seed — blank or random = randomize, integer = fixed
  • negative_prompt — optional
  • enhance — true / false
  • name — display label
